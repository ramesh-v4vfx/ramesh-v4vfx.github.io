％ Percent of a Number

Find X% of a number
0 — value
What this does: it scales a number by a percentage — telling you how much X% actually comes out to when applied to a value.
Example: a shop offers 15% off a ₹2,400 jacket. Percentage = 15, Value = 2400 → discount is ₹360. Same idea works for tips, tax, interest, or commission on any amount.
